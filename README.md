🚀 Projeto Integrador (PI)

📚 Sobre o Projeto

O Projeto Integrador (PI) tem como objetivo reunir e aplicar, na prática, os conhecimentos adquiridos ao longo do semestre, integrando diferentes áreas da tecnologia em um único projeto.

O desenvolvimento envolve programação, desenvolvimento web, Ciência de Dados, banco de dados, levantamento de requisitos, integração de sistemas e infraestrutura em nuvem.

A proposta é transformar os conhecimentos teóricos adquiridos durante as aulas em uma aplicação prática, explorando as etapas de desenvolvimento de software, desde a organização dos requisitos até a implementação e disponibilização do sistema.

Este projeto representa não apenas a aplicação dos conteúdos estudados, mas também a evolução técnica e profissional desenvolvida ao longo do semestre.

🎯 Objetivos

* Aplicar os conhecimentos adquiridos durante o semestre.
* Integrar diferentes áreas da tecnologia em um projeto prático.
* Desenvolver e integrar uma aplicação web.
* Aplicar conceitos de programação e engenharia de software.
* Trabalhar com Ciência de Dados e organização de informações.
* Compreender o levantamento e a análise de requisitos.
* Explorar a hospedagem de aplicações utilizando computação em nuvem.
* Desenvolver habilidades de resolução de problemas e integração de sistemas.

🏗️ Arquitetura da aplicação

A aplicação possui uma arquitetura separada entre front-end e back-end, utilizando serviços da Amazon Web Services (AWS).

Front-end

A interface da aplicação é hospedada no Amazon S3, serviço utilizado para disponibilizar os arquivos do site.

Back-end

A aplicação back-end é desenvolvida em Java com Spring Boot e executada em uma instância Amazon EC2.

Comunicação entre os componentes

O front-end e o back-end são integrados por meio de requisições HTTP, conforme a configuração da aplicação.

Essa organização permite compreender, na prática, a separação de responsabilidades entre a interface do usuário e a lógica executada no servidor.
