🚀 Projeto Integrador (PI)

📚 Sobre o Projeto

Este repositório corresponde ao nosso Projeto Integrador (PI), desenvolvido com o objetivo de reunir e aplicar os conhecimentos adquiridos ao longo deste semestre.

O projeto integra diferentes áreas da tecnologia, transformando os conteúdos aprendidos em sala de aula em uma aplicação prática. Durante o desenvolvimento, foram explorados conceitos de desenvolvimento web, programação, ciência de dados, banco de dados, levantamento de requisitos e infraestrutura em nuvem.

Além de representar o aprendizado acadêmico, este projeto demonstra a importância do planejamento, da dedicação, da resolução de problemas e da integração entre diferentes áreas para a construção de uma solução tecnológica.

🎯 Objetivos do Projeto

* Aplicar os conhecimentos adquiridos durante o semestre.
* Integrar diferentes disciplinas e áreas da tecnologia.
* Desenvolver uma aplicação utilizando tecnologias modernas.
* Compreender as etapas de planejamento, implementação e disponibilização de um sistema.
* Desenvolver habilidades de programação, análise de dados e organização de informações.
* Praticar conceitos de engenharia de software, versionamento e computação em nuvem.

💻 Tecnologias Utilizadas

* Java: linguagem utilizada no desenvolvimento do back-end.
* Spring Boot: framework para construção da aplicação back-end.
* Front-end Web: desenvolvimento da interface e das funcionalidades visuais.
* Amazon S3: hospedagem do front-end.
* Amazon EC2: execução do back-end na nuvem.
* Git e GitHub: versionamento e gerenciamento do código-fonte.
* Ciência de Dados: aplicação dos conceitos relacionados à análise e ao tratamento de dados.
* Banco de Dados: conceitos de organização, modelagem e gerenciamento de informações.

☁️ Arquitetura da Aplicação

A aplicação utiliza uma arquitetura dividida entre front-end e back-end, com hospedagem na Amazon Web Services (AWS).

* Front-end: hospedado no Amazon S3, responsável pela interface com o usuário.
* Back-end: desenvolvido em Java com Spring Boot e executado em uma instância Amazon EC2.
* Comunicação: integração entre os componentes por meio de requisições HTTP, conforme a implementação do sistema.

Essa estrutura permite aplicar na prática conceitos de desenvolvimento web, integração de sistemas e infraestrutura em nuvem.
